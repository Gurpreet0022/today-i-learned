# SQL Things to keep in mind

**Date** : 09-09-2026

1. Use Indexes carefully because unnecessary indexes can slow down the performance.
2. Use EXPLAIN to see the working of your queries , so you can optimize them as needed.
3. Don't use LIKE operator , avoid using it wherever possible.
4. Use WHERE for filterattion so you can filter neccessary data.
5. We can also put JSON data in MySQL.
6. While making connections in MySQL sometimes Cursor approach may not work so you can try using SQLAlchemy.
