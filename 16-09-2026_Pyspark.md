# Commonly faced Pyspark Issues and their solutions
1. If your system has less than 8GB RAM then don't open multiple pyspark sessions simultaneoulsy because it will slow down the performance.
2. Make sure pyspark and python are activated with the same environment, otherwise it may give errors.
3. Avoid df.collect() on large datasets / or in production because it may give OutOfMemory Error , instead use df.limit(n) or df.take().
4. Instead of using Python UDF use pysaprk's built in fucntions.
