# MongoDB ServerConnection Timeout Error

**Date:** 07-09-2026
**What happened:** Was connecting MongoDB to Jupyter Notebook and got ServerConnection Timeout error
**What I learned/fixed:** Add IP Address into IP Access List (IP White List)
**Why it matters:** Check whether the IP Address is added into IP Access List or not because otherwise you may stuck into updating your libraries , Switching wifi connection , Fixing TLS and some other things which are time consuming if you did not check it first.
